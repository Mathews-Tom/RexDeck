# Changelog

## Unreleased

- `status` and `plugins` report `missing-dependency` (nonzero exit) when an enabled integration's upstream tool is no longer on `PATH`, instead of a generic `fault`. The README documents every integration state and how to install an exact public source commit for integrations merged after the latest release.
- Add the independently selectable Usage integration: `rexdeck enable usage` runs unmodified tokscale 4.21.0 as `tokscale tui --client omp` in a native pane. It keeps tokscale's normal online pricing/refresh and its `r` manual refresh and `Shift+R` auto-refresh; RexDeck never forces `--offline`, passes `--refresh`, or invokes login, submit, autosubmit or report. Usage is machine-wide, not a project filter, and the README discloses tokscale's network, provider-credential and account-control behaviour.
- Add the independently selectable Markdown integration: `rexdeck enable markdown` hosts unmodified markdown-reader 1.35.4, which draws Mermaid as Unicode text diagrams inside the Rex pane, alongside rendered prose, tables and code. The palette action browses the invoking directory, and the action's `file` argument (absolute, `file://` or relative to the invoking terminal) opens a selected `.md`/`.markdown` file. Invalid selections fail before a pane opens. The shared host gains a `document` context, which passes the validated target to the tool as its final argument.
- Add configurable pane placement and size: `rexdeck enable <id> --placement {right,left,below,above} --size 20-80`. Invalid values are rejected before any change; omitted options keep the integration's saved layout across refresh and disable/enable; status and listings report it. Layout is stored in each integration's own receipt (still schema 3; receipts without a layout keep the original right/50% split), so changing Git's layout leaves Files untouched.
- Consolidate Files and Git onto one shared native host contract: `rexdeck.integrations` descriptors declare identity, qualified versions, license, launch context, shell-less argv, default layout and capability disclosure; the shared `host/main.lua` action and `host/launch.py` launcher replace the Files/Git branches, and lifecycle ownership handles any number of sibling loaders. Loader bytes, deployment paths, settings schema 2 and receipt schema 3 stay compatible; run `rexdeck enable <id>` after upgrading to refresh each applied integration.
- `rexdeck plugins` and aggregate `status` rows disclose each integration's tool, versions, license, context, capabilities and default layout. Document adding an interactive terminal tool and the limits for one-shot, data-backed and GUI programs.

## 0.1.1 — 2026-11-08

- Add `rexdeck plugins` to list all available integrations and their enabled/disabled state as JSON. Discovery works before setup, reporting `not-configured`; configured inspection reuses aggregate status, preserving healthy siblings and nonzero failure reporting when a plugin cannot be inspected. Listing does not change registration or install dependencies.
- Published the approved main-CI wheel/sdist to GitHub and PyPI from tag `v0.1.1`; public asset and registry hashes match.

## 0.1.0 — 2026-11-08

RexDeck never runs Homebrew or installs, upgrades, removes or supervises upstream package transactions. Restrict the source distribution to product source, tests, metadata, and public documentation; globally ignored local evidence is not packaged.
- Prepare Python 3.12+ metadata, packaged MIT license and project URLs. Document macOS arm64/Rex API 10 baseline, upstream unbundled licenses, installed-package checks and private-versus-owner visual proof limits.

- Resolve Git validation through absolute PATH directories and preserve discovery errors. Retain healthy integration status when a sibling receipt is invalid; validate only deployment/sibling artifacts needed by the selected operation. Clarify cleanup of applied-but-disabled integrations before package removal.
- Pin applied Lua/Python launch behavior together with isolated Python imports; avoid DNS for local cwd URIs, report symlink loops, and retain acknowledgement on interrupted focus restoration. Freeze socket/config selection without lexical symlink retargeting, verify the running server's config before writes, preserve saved approval across default-server changes, reject redirected app roots and oversized planned writes before mutation, preserve later installations on repeated disable, and recover owned changes on SIGTERM/SIGHUP while collecting rollback conflicts.

Keep package, preferences, and receipt/lock roles separate; use settings v2 and receipt v3, refusing old/foreign formats without automatic adoption. - Package the native Files Lua action and Python launcher so installed RexDeck works outside a checkout. Replace manual workspace flags and shell wrappers with one-time `setup`, `enable files`, `status`, and `disable files`; persist the explicitly approved Rex target and derive Files state paths automatically.

Require verified ownership and rollback safety before explicitly migrating existing state or removing obsolete owned artifacts; no automatic migration command is added.

- Preserve tracked native registration, source integrity, conservative conflicts, atomic rollback, config symlink/mode preservation, and cancellation diagnostics. Package location is update provenance rather than ownership identity, so re-enabling refreshes an unchanged owned integration after reinstall. Refuse legacy receipts; old LazyRex installations require explicit prior-code cleanup.
- Make LazyRex optional for future integrations that actually need an existing capability; defer the broader collection. No hooks, fonts, autostart, automatic Rex/manager installation, or live migration command is included.
